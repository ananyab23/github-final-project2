# Paradise Nursery - Shopping Cart Application

Welcome to **Paradise Nursery**, an interactive e-commerce web application where plant enthusiasts can explore, select, and purchase a variety of house plants to make their homes greener and healthier.

---

## 🌿 Project Overview

Paradise Nursery provides a seamless shopping experience for plant lovers. The application allows users to browse through curated categories of indoor plants, view details like pricing and descriptions, add items to a shopping cart, and manage their orders with dynamic cost and quantity updates.

---

## ✨ Features

- **Landing Page:** Welcoming interface with an overview of our mission and a button to get started.
- **Plant Catalog (Product Listing):** 
  - Organized into distinct categories (e.g., Air Purifying, Aromatic, Low Maintenance).
  - Displays plant images, names, descriptions, and prices.
  - Interactive "Add to Cart" buttons that update upon selection.
- **Navigation Bar:**
  - Dynamic cart icon showing total items currently in the cart.
  - Quick navigation between the catalog and the cart.
- **Shopping Cart Page:**
  - Detailed overview of selected plants with quantities and item subtotals.
  - Increment (`+`), decrement (`-`), and remove/delete options for each plant.
  - Dynamic calculation of total shopping cost.
  - "Continue Shopping" button to easily return to the store catalog.
  - Checkout confirmation modal/alert.

---

## 🛠️ Tech Stack & Dependencies

- **Frontend:** React.js
- **State Management:** Redux Toolkit (`@reduxjs/toolkit`, `react-redux`)
- **Styling:** CSS3 / HTML5
- **Icons:** React Icons / Font Awesome
